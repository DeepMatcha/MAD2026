# 백엔드 개발 시작점

[`API.md`](../API.md)의 Repository와 Service가 앱에 노출하는 계약이다. 이 모듈의 학교 동기화 인터페이스는 백엔드 내부에서 사용한다. 화면 팀은 `:demo-data`로 같은 공통 계약을 사용한다.

## 첫 구현 단위

1. 합성 과목·과제 데이터와 `SchoolAssignmentSource`, `SchoolAssignmentSyncStore`로 학교 과제 동기화의 성공·실패 경로를 만든다. 과목별 마지막 성공 체크포인트를 읽고, 과제 변경과 새 체크포인트를 로컬에 함께 기록한다.
2. 로컬 데이터를 `SchoolRepository`에서 관찰하게 한다. 재수집 시 앱 ID·사용자 수정·완료·숨김을 보존하고, 원본 날짜 변경은 사용자 승인 대상으로 남긴다. 확인된 삭제만 반영한다. 페이지 수집 실패 시 기존 데이터와 체크포인트를 유지하고 해당 과목의 실패를 기록한다.
3. `SyncService`에 과목별 상태, 취소·재시도, 주기 실행을 연결한다. 비활성 과목은 제외하고 실패한 과목만 다시 시도할 수 있게 한다. 계약의 기본 주기는 60분이다.

학교 API 인증과 세션 갱신을 연결하면 같은 경계에서 합성 수집원을 실제 수집원으로 교체할 수 있다. Google Calendar, AI 분석, 알림은 각 공통 계약에서 이어서 구현한다.

```sh
./gradlew :backend:assembleDebug
```
